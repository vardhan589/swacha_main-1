# Swacha Main App

## Project Description
Swacha Main is an Android application developed to promote cleanliness awareness and help users manage waste-related activities efficiently. The application provides a simple and user-friendly interface for reporting waste issues and maintaining clean surroundings.

## Features
- User-friendly Android application
- Waste issue reporting
- Clean and simple UI design
- Image upload support
- Local data storage
- Fast and responsive performance

## Technologies Used
- Android Studio
- Java / Kotlin
- XML
- Firebase
- SQLite / Local Storage

## Screenshots

## APK File
APK file is included in the repository for testing and installation.

## Project Structure
- `app/` – Main application source code
- `gradle/` – Gradle build files
- `screenshots/` – Application screenshots
- `README.md` – Project documentation

## How to Run
1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle files
4. Run the application on emulator or Android device
